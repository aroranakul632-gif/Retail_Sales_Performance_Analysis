
# Retail Sales Performance Analysis

## Project Overview
This project analyses retail sales data using Python, Pandas and NumPy to understand sales performance and identify business opportunities.

## Dataset Information
- Dataset: 01_retail_sales.csv
- Original Records: 502
- Records After Cleaning: 500
- Columns: 10

## Tools and Technologies
- Python
- Pandas
- NumPy
- Visual Studio Code
- Git and GitHub

## Project Tasks
1. Data loading and inspection
2. Missing value and duplicate handling
3. Revenue calculation
4. Product-wise sales analysis
5. City-wise revenue analysis
6. Monthly sales analysis
7. Top customer analysis
8. Payment method analysis
9. Large order detection using IQR
10. Category-wise analysis
11. Statistical analysis using NumPy

## Key Findings
- Total Revenue: 13,954,120
- Total Quantity: 1,480
- Average Order Value: 27,908.24
- Highest Revenue Product: Keyboard
- Highest Revenue City: Delhi
- Best Revenue Month: February
- Highest Revenue Payment Method: UPI
- Highest Revenue Category: Accessories

## How to Run the Project
1. Install Python.
2. Install required libraries:

```bash
pip install pandas numpy
```

3. Run the Python file:

```bash
python src/analysis.py
```
